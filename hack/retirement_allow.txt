# The retired-name allowlist: where a name the retirement manifest (hack/retirement.json) records may still
# stand in this tree, by the role of the file it is in.
#
# Every line the retired-name search returns must be accounted for here:
#   git grep -n -i -E "<the manifest's scenario, modules, adapters, generators, playbooks, licence ids, assets and vendors>"
# One row per path, or per path:line[,line…], then a tab, the category, a tab, and the reason. A whole-file row only
# where one role covers the whole file: the manifest, the harness, or a history or evidence document. No row may
# cover a location that holds runnable provisioning content. The categories are the manifest's allowed_locations
# roles (this_manifest, frozen_schemas, negative_fixtures, evidence_and_history, protocol_reference, harness,
# narrative_name).
# hack/retirement_guard.sh (CI's `retirement` job) reads this file as its allowlist, over the same search plus the
# retired image digests, every term taken from the manifest. It fails on a line no row accounts for; on a row that
# matches nothing (removed, never kept in case); on a row that covers a maintained surface — the catalog, the
# modules, the current schemas, the installer and its answers, the wrapper, the registries, what the binary embeds
# or the release carries — save the embedded frozen files the manifest's in_a_binary roles name, under their role;
# on a whole-file row the rule above does not allow; on a role the manifest names by path (this_manifest,
# frozen_schemas, negative_fixtures) given to another path; and on a real digest in a negative fixture or a retired
# one outside the manifest. Line numbers are this commit's; an edit that moves a line moves its row in the same
# change.
